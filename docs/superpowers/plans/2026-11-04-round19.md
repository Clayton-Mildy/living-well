# Round 19 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** KC's four round 19 points:
- upgrade notice days and leave-in-a-row months become settings;
- one Contacts menu replaces Contacts and Directory;
- a field trip blocks its day in the weekly schedule builder;
- Few visits becomes a distinct button on Next month.

**Architecture:**
- **Shared rules first:** notice kind `upgrade` and `leaveMaxMonths(s)` replace hard-coded rules.
- **Web screens next:** Settings, Roles/nav, the builder, and Next month consume them.
- **Last:** the seed's terms text and e2e.
- **Parallel tracks:** four tracks touch different files: A (Tasks 1→2), B (Task 3), C (Task 4), D (Task 5). They can run in parallel worktrees, then merge before Task 6.

**Tech Stack:** pnpm monorepo, TypeScript, React 18 (data router), Hono + Drizzle + Postgres (5434), Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-04-round19-design.md`

## Global Constraints

- **Code conventions:**
  - Shared immer actions live in `packages/shared/src/actions` (`defineAction`) and pure rules in `packages/shared/src/rules`. Role checks run server-side through `can`/`permit()`.
  - Every string exists in EN and ID, with ID typed `Same<typeof EN.x>`.
  - Web unit tests run from the repo root: `pnpm exec vitest run <path>`.
- **UI rules:** dense and phone-first, 44 px targets, ink/grey/white on the warm staff skin, no pastel tints, no descriptive filler text. Phones use iOS grouped lists, and tablets must work.
- **Seed:** stays RNG-neutral. `CP_SEED_SMALL=1` keeps its 5 members. Club state stays under 7,500,000 characters at the real date and at 2026-12-30.
- **Ports:** API dev port 8788, never 8787.
- **Disk:** it's tight. Drop any `citrapremier_e2e_<name><n>` database and `.e2e-<name>` folder you create.
- **Upgrade:** default 1 day (December's upgrade is asked by 30 Nov), range 1–60. The take-back case (back to the plan in force the day before) needs no notice.
- **Leave in a row:** `leaveMaxMonths` default 2, range 1–6.
- **Owner gate:** any notice kind and `leaveMaxMonths` go through the owner gate "pricing", the same as the other notice days.
- **Contacts:** label "Contacts" / "Kontak". The nav key `directory` is retired. A stored `directory` grid cell is read as `contacts`, keeping the more permissive value (edit > view > off). Menus count 31. `/directory` redirects to `/contacts`.
- **Trip block:** reads "Field trip · {title} · {from}–{to} · no sessions". The day header reads "{Day} {n} · Field trip".
- **Few visits button text:**
  - before: "Few visits · opens {alertDay}" (grey);
  - open: "Few visits · {n}" (plus " · {c} called" when c > 0);
  - closed: "Few visits · {n} · {c} called".
- **Commit trailer:** `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Rulings (made while planning; easy to reverse)

- **R1** Upgrade notice joins `NOTICE_KINDS`. The take-back case is found by `changeKind`'s existing `to === before` check, which now returns a third value `'takeBack'`. `inTime` and `noticeCheck` treat `'takeBack'` as "before the 1st", as the old upgrade rule did. Callers that pass `changeKind`'s result keep working.
- **R2** `leaveMaxMonths` lives on `ClubSettings.leaveMaxMonths?` and is saved by `club.updateSettings`, never in the `notice` object.
- **R3** The Contacts merge is done by reading, not by migrating stored data. `accessOf(s, role, 'contacts')` takes the more permissive of the stored `contacts` and `directory` cells, and `access.setRole` writes only `contacts`, dropping the `directory` cell on save.
- **R4** The builder reads trips with the existing `eventsOn(s, date)` filtered to `kind === 'outing'`. No new rule module is needed.
- **R5** The Few visits button lives in `NextMonthList.tsx` (Members tab only). `FewVisitsCard.tsx` is deleted, and `fewLine` moves into the new button file.

## Review Focus

1. **Upgrade take-back:** a member with a downgrade scheduled for December who moves back to their current plan on 30 Nov, with upgrade days set to 5, is still allowed (it's a take-back). Pinned in Task 1.
2. **Leave max lowered while leave exists:** a member with 2 leave months already booked when the Owner sets the maximum to 1 keeps the booked months, and only new requests over the maximum are refused. Pinned in Task 1.
3. **A role with Directory edit and Contacts hidden:** stored `directory: 'edit'` and no `contacts` cell reads as Contacts Edit. A role with `contacts: 'view'` and `directory: 'edit'` reads as Edit. Pinned in Task 3.
4. **A multi-day trip across a week boundary** (Thu–Mon): Thu and Fri are blocked in this week, Mon in the next. Pinned in Task 4.
5. **The Few visits deep link** `?few=1` (from the notification and Also today) still opens the sheet with the card gone. Pinned in Task 5.
